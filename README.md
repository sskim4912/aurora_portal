# AURORA 현장 업무 포털

카드형 반응형 웹페이지입니다. 별도 설치나 외부 리소스 없이 `index.html`을 브라우저에서 열 수 있습니다.

연결된 메뉴: 식사 신청, 영수증 관리, 숙소 민원(Google Forms), 차량 운행·사고접수. 각 업무는 새 창으로 열립니다.
숙소 임차료 메뉴는 `rent/` 페이지를 새 탭으로 엽니다. 기존의 다른 메뉴는 유지합니다.

로컬 확인: `python -m http.server 8000`
이전 3안 비교 화면은 `layouts.html`에 보관했습니다. 게시하지 않았습니다.

## 운영 배포

GitHub Pages용 워크플로는 `.github/workflows/pages.yml`입니다.
저장소 Settings → Pages → Source를 **GitHub Actions**로 선택하면 main 업데이트 시 자동 배포됩니다.
공개 배포에는 `index.html`, `assets/`, `rent/`만 포함합니다. 공통 다운로드용으로 승인된 `rent/downloads/` CSV를 포함합니다. 별도 테스트 자료와 화면 캡처는 포함하지 않습니다.


## 숙소 임차료 전표 작성 지원

`rent/`는 Windows Selenium 프로그램과 CSV를 준비하는 정적 페이지입니다. STEP 01은 관리자 CSV 등록, STEP 02는 최신 원본 다운로드, STEP 03은 OneDrive 프로그램 공유 화면 열기입니다. 관리자 등록은 별도 서버 API가 연결된 경우에만 사용합니다. 현재 운영 서비스 연결과 배포는 하지 않았습니다. 연결·검증 방법은 [server/README.md](server/README.md)를 참고하세요.

- 프로그램 실행, EAS 로그인·전표 작성은 Windows PC에서 직접 진행합니다. ‘사용 전 확인해 주세요’를 누르면 제공된 화면 ①~⑨ 순서의 프로그램 실행 방법(다운로드 열기 → 출처 확인 및 경고 처리 → 파일 열기 → CSV 선택)이 펼쳐집니다.
- 접속 화면은 클라이언트 화면 잠금입니다. 비밀번호 원문을 저장·로그 출력하지 않고 이름과 접속 상태만 sessionStorage에 저장합니다. 서버 인증이나 파일 접근 통제가 아닙니다.
- 공통 CSV는 `rent/downloads/`의 첨부 원본 파일입니다. 인코딩, BOM, 줄바꿈 및 모든 바이트를 변경하지 않고 원래 이름으로 제공합니다. CSV 전체 미리보기는 기본 접힘 상태이며, 클릭하면 파일을 읽어 두 번째 행을 항목명으로 사용하고 마지막 자료까지 모두 텍스트로 표시합니다. PC에서는 14개 열을 화면 폭에 맞춰 줄바꿈하고, 모바일에서는 항목명과 값을 자료별 카드로 표시하여 가로 스크롤을 없앴습니다. 스크롤 중에는 사이트 헤더와 미리보기 제목, PC의 항목명 또는 모바일의 자료 순번을 고정합니다. 다운로드 원본과 미리보기 파싱은 분리하고, 실제 자료를 로그나 공유용 화면 캡처에 넣지 않습니다.
- 공개 배포 후 파일 URL은 로그인과 무관하게 누구나 접근할 수 있습니다. 새 서버 API는 서버에서 관리자 인증을 검사하며, 공용 CSV를 영속 디스크에 저장합니다. API가 연결되지 않은 정적 페이지는 기존 CSV를 유지하며 미연결 상태를 표시합니다. 기존 브라우저 IndexedDB의 로컬 파일은 더 이상 읽거나 다운로드 대상으로 사용하지 않습니다.
- 명시적인 배포 요청이 있을 때만 main에 반영하고 기존 Pages workflow로 배포합니다. `rent/` 전체를 복사하므로 공통 다운로드 CSV와 전체 미리보기 모듈도 포함됩니다.
- 로컬 실행: `python3 -m http.server 8000 --bind 127.0.0.1` 후 `/rent/` 접속.
