# AURORA 현장 업무 포털

카드형 반응형 웹페이지입니다. 별도 설치나 외부 리소스 없이 `index.html`을 브라우저에서 열 수 있습니다.

연결된 메뉴: 식사 신청, 영수증 관리, 숙소 민원(Google Forms), 차량 운행·사고접수. 각 업무는 새 창으로 열립니다.
숙소 임차료 메뉴는 `rent/` 페이지를 새 탭으로 엽니다. 기존의 다른 메뉴는 유지합니다.

로컬 확인: `python -m http.server 8000`
이전 3안 비교 화면은 `layouts.html`에 보관했습니다. 게시하지 않았습니다.

## 운영 배포

GitHub Pages용 워크플로는 `.github/workflows/pages.yml`입니다.
저장소 Settings → Pages → Source를 **GitHub Actions**로 선택하면 main 업데이트 시 자동 배포됩니다.
공개 배포에는 `index.html`, `assets/`, `rent/`만 포함합니다. CSV 원본, 테스트 자료, 미리보기 화면 캡처는 포함하지 않습니다.


## 숙소 임차료 전표 작성 지원

`rent/`는 Windows Selenium 프로그램과 CSV를 준비하는 정적 페이지입니다. 프로그램 다운로드 버튼은 지정된 OneDrive 공유 화면을 새 탭으로 열며, EXE 실행이나 EAS 로그인·전표 작성은 PC에서 직접 진행합니다.

- 이름과 접속 비밀번호를 사용하는 **클라이언트 화면 잠금 시안**입니다. 검증용 다이제스트만 코드에 포함하며 원문 비밀번호를 브라우저 저장소나 로그에 쓰지 않습니다. 이름과 화면 잠금 해제 상태만 `sessionStorage`에 저장합니다. 서버 인증·파일 접근 통제가 아니며 운영 인증은 별도 서버 세션/인증 서비스가 필요합니다.
- CSV 한 개, 최대 25MiB(화면상 25MB)를 처리합니다. UTF-8(BOM 포함), CP949/EUC-KR을 지원합니다. 첫 행은 반영순서, 둘째 행은 지정된 14개 항목명이어야 하고 데이터가 한 건 이상 있어야 합니다. CSV 구문·헤더·열 수를 검증하며 EAS 업무상 데이터 유효성은 PC 프로그램에서 확인합니다.
- 원본 `ArrayBuffer`와 미리보기용 파싱 결과를 분리하여 IndexedDB에 저장합니다. 저장 트랜잭션 완료 뒤에만 업로드 완료를 표시합니다. 다운로드는 원래 파일명과 바이트를 유지합니다. 잘못된 파일 또는 저장 실패는 이전 정상 파일을 교체하지 않습니다.
- 최초 5건을 텍스트로 렌더링하며 CSV 값은 HTML로 실행하지 않습니다. 로그아웃 후에도 CSV는 해당 브라우저에 남습니다. 같은 브라우저 프로필에서는 다른 접속 이름도 이 파일을 볼 수 있으므로 공용 PC에서 유의해 주세요. 다른 PC와 공유하거나 서버에 업로드하지 않습니다. 브라우저 데이터 삭제·비공개 모드 정책에 따라 로컬 파일이 제거될 수 있습니다.
- HTTPS 또는 localhost에서 실행해야 합니다. `file://` 실행 대신 `python3 -m http.server 8000 --bind 127.0.0.1` 후 `/rent/`를 엽니다.

### 확인한 범위

Chromium 브라우저에서 잘못된 비밀번호·공백 이름 거부, 정상 접속, 세션 새로고침·로그아웃, 다운로드 비활성화, 가상 60건 CSV의 2줄 헤더·14열·인코딩 3종, 인용 쉼표·큰따옴표·줄바꿈, 선행 0 보존, 업로드/다운로드 바이트 일치, 잘못된 확장자·빈 파일·25MB 초과·구문/헤더/인코딩 오류 거부, 저장 트랜잭션 실패 시 이전 파일 유지, 드래그앤드롭, 최신 파일 교체·복원, HTML 비실행을 검증했습니다. 320·390·768·1440px에서 페이지 가로 넘침 없이 표 내부 스크롤을 확인했고, 다른 포털 카드 9개와 기존 링크가 동일한지 비교했습니다.

사용자가 언급한 실제 첨부 CSV는 작업 시 제공되지 않아 가상 데이터로 검증했습니다. 실제 개인정보 CSV와 공유용 화면 캡처는 이 저장소 및 배포 산출물에 포함하지 않습니다. OneDrive의 실제 파일 다운로드 완료, Windows EXE 실행, EAS 접속·작성, 서버 인증·공용 저장은 이 페이지에서 검증하거나 수행하지 않습니다.
