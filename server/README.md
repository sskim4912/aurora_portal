# Python 로컬 시연 API

**운영용 구현은 Firebase로 변경했습니다. [Firebase 연결 안내](../firebase/README.md)를 따르세요. 아래 Python 서버는 외부 서비스 없이 가상 데이터로 시연하기 위한 보조 구현입니다.**

GitHub Pages는 그대로 정적 웹사이트를 배포합니다. 업로드는 Pages와 별개인 Python 3.10+ HTTPS 서버 한 대 및 영속 디스크가 필요합니다. 외부 인증·호스팅·공용 디스크는 아직 연결되지 않았습니다. 서버는 표준 라이브러리만 사용합니다. 브라우저 화면 잠금은 관리자 인증과 무관합니다.

## 서버 준비

1. `python3 server/rent_api.py --hash-password`로 별도의 관리자 비밀번호 해시를 만듭니다. 비밀번호는 숨김 입력입니다. 출력 해시는 호스팅 서비스의 비밀 환경 설정에 저장하고 커밋하지 않습니다.
2. 호스팅 서비스의 안전한 환경 설정에서 다음을 지정합니다. 비밀번호나 해시를 채팅에 보내지 않습니다.
   - `RENT_ADMIN_USER`: 별도 관리자 계정명
   - `RENT_ADMIN_PASSWORD_HASH`: 위 명령의 해시
   - `RENT_DATABASE`: 영속 디스크상의 SQLite 경로 (웹 공개 디렉터리 밖)
   - `RENT_ALLOWED_ORIGINS`: `https://sskim4912.github.io` (쉼표로 추가 출처 지정 가능)
   - `PORT`: 기본 8000
3. `python3 server/rent_api.py`를 프로세스 관리자로 실행합니다. 127.0.0.1에 바인딩하므로 HTTPS 리버스 프록시가 같은 서버에서 이 포트로 전달해야 합니다. HTTP 외부 노출 금지. 프록시 요청 제한은 25MiB 이상, 시간 제한 및 IP 기준 요청 제한을 설정합니다. 공유 IP 환경에서 로그인 제한이 함께 적용될 수 있습니다. 다중 프로세스 대신 단일 프로세스로 실행합니다(세션은 메모리에 있음).
4. `rent/index.html`의 `meta[name="rent-api"]` content에 HTTPS API 원점을 설정합니다. 비밀값이 아닙니다. 기본 빈 값은 같은 원점을 검사하고 미연결이면 기존 CSV 다운로드를 유지합니다. 허용 Origin은 경로가 아니라 위 원점입니다.
5. 로컬 기능과 HTTPS CORS를 다시 검증한 후에만 별도 배포 요청에 따라 배포합니다. 이번 작업은 push/Pages 실행/운영 CSV 교체를 하지 않았습니다.

기존 CSV는 서버에 자동으로 가져오지 않습니다. 관리자가 파일과 대상 월을 지정하고 등록한 다음 서버가 저장한 원본을 제공합니다. 업로드 크기/CSV 확장자/UTF-8(BOM 포함)·CP949/제어 문자/인용부호/두 헤더/14열/순번/최소 1건을 서버에서 검사합니다. 업무별 날짜·계정 유효성은 PC 프로그램 검증을 유지합니다. 대상 월은 관리자가 명시하는 메타데이터이며 날짜 값을 변환하지 않습니다.

SQLite 단일 트랜잭션으로 원본 BLOB와 메타데이터를 함께 교체합니다. 실패 시 기존 데이터는 유지합니다. 백업은 SQLite backup API 또는 서비스 정지 후 복사로 운영자가 수행해야 합니다. 최신 파일 한 개만 저장하며 이력/복구 UI는 없습니다. 다운로드는 공개이며 관리자 권한은 쓰기에만 필요합니다.

관리자 토큰은 서버에서 발급·검증하며 30분 만료, 브라우저 메모리에만 유지합니다. 새로고침은 관리자 재인증이 필요하지만 기존 화면 잠금 접속은 같은 탭에서 유지됩니다. 로그아웃은 토큰을 폐기합니다. 서버 재시작 시 모든 세션도 폐기됩니다. 임의 Origin 요청은 거부하며 Bearer 헤더 없이 업로드할 수 없습니다. 화면 잠금 비밀번호는 서버에 전달하지 않습니다.

미리보기는 다운로드 원본과 별도로 텍스트 파싱하며 DOM textContent만 사용합니다. 버전이 바뀐 오래된 다운로드 요청은 409를 반환합니다. 열린 탭은 30초마다 최신 메타데이터를 확인합니다. 원본 다운로드는 변환하지 않습니다.

## 로컬 시연

저장소 루트에서 `python3 server/demo.py`를 실행합니다. 별도 임시 디렉터리에 가상 60건과 매번 새로 생성되는 관리자 계정을 만듭니다. 출력되는 경로는 0600 권한의 로컬 인증 파일이며 비밀번호 자체는 출력하지 않습니다. 인증 파일은 공유하거나 커밋하지 않습니다. 테스트 종료 후 프로세스를 중지하고 해당 임시 디렉터리를 삭제합니다. 기존 운영 CSV나 DB를 읽거나 교체하지 않습니다. 브라우저 테스트 시 출력된 파일 경로를 `RENT_TEST_AUTH_FILE`로 지정합니다.

## 검증

- `python3 -m unittest discover -s tests -v`: 가상 데이터만 사용하는 API 테스트. 인증/위조 토큰/만료/로그아웃, 인코딩 4종, 원본 일치, 저장 실패·잘못된 파일 보존, 버전/재연결, 경로 접근 차단.
- `tests/browser.cjs`: Chromium 및 Playwright가 있는 환경에서 실행. **가상 데이터용 별도 API**를 127.0.0.1:8000에서 시작해야 합니다. `RENT_TEST_AUTH_FILE`은 테스트 관리자 JSON 파일 경로(웹루트 밖, 0600), `RENT_TEST_UI_PASSWORD`는 기존 화면 잠금 테스트용 환경변수입니다. `PLAYWRIGHT_MODULE`로 설치된 Playwright 경로를 지정할 수 있습니다. 이 테스트는 해당 로컬 API의 최신 파일을 가상 CSV로 교체합니다. 운영 API에 실행하지 않습니다. 결과와 가상 화면은 `/tmp/aurora-artifacts/`에 저장합니다.

실제 다른 PC의 HTTPS API 접근과 운영 영속 디스크 복원은 호스팅 연결 후 검증해야 합니다. 로컬 독립 브라우저 컨텍스트의 공유 다운로드는 검증했습니다.
