PC 프로그램 준비
i
Selenium 프로그램은 PC에서 실행됩니다.

이 페이지에서 파일을 준비한 후 PC 프로그램의 안내에 따라 전표 작성을 진행하세요.

STEP 01↓

프로그램을 실행해 주세요

링크된 파일을 바탕화면에 저장한 뒤, EXE 실행 파일을 실행해 주세요.

Windows PC에서 직접 실행

OneDrive 공유 화면에서 다운로드한 뒤 실행하세요. EAS 로그인은 PC 프로그램에서 진행합니다.

프로그램 다운로드 ↗ (OneDrive, 새 탭)공유 화면 열기 · 웹페이지에서 자동 실행하지 않습니다.
STEP 02↑

최신 CSV를 업로드하세요

숙소 임차료 전표 작성에 사용할 최신 CSV 파일을 선택해 주세요.

사용 전 확인해 주세요
  • 프로그램은 Windows PC에서 직접 실행합니다. 웹페이지가 PC의 EXE를 자동 실행하지 않습니다.
  • CSV의 입력 순서 행·항목명 행·원본 인코딩을 보존합니다. 다운로드는 원본 바이트 그대로입니다.
  • 시안의 CSV는 해당 브라우저에만 저장되며, 로그아웃해도 최신 CSV는 남습니다. 공용 PC 이용 시 유의해 주세요.
  • EAS 로그인과 전표 작성·검토는 PC 프로그램의 실제 동작에 따라 진행합니다.
  • 웹페이지의 로그인 비밀번호를 EAS에 전달하거나 EAS 비밀번호로 사용하지 않습니다.
  • 현재 접속 화면은 클라이언트 화면 잠금이며 서버 인증이나 파일 접근 통제가 아닙니다. 운영 인증에는 별도의 서버 세션 또는 인증 서비스가 필요합니다.
